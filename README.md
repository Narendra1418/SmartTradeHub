# SmartTradeHub 📈

A full-stack stock portfolio and market analytics platform that enables users to track stocks, manage virtual portfolios, create watchlists, and receive real-time market alerts.

> 🚧 Project Status: In Development

## Features

- JWT Authentication
- Google OAuth 2.0 Login
- Portfolio Management
- Watchlists & Alerts
- Redis Caching
- Role-Based Access Control
- Subscription System
- Admin Dashboard
- Dockerized Infrastructure

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Prisma ORM

### Database
- PostgreSQL

### Infrastructure
- Redis
- Docker
- AWS

## Project Structure

frontend/
backend/

## Getting Started

### Clone Repository

git clone <repo-url>

### Install Dependencies

npm install

### Start Containers

docker compose up -d

### Run Backend

npm run dev

### Run Frontend

npm run dev
